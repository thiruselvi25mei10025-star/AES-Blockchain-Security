AES Encryption and Blockchain Security System

Project Description

This project uses Python to demonstrate AES-256 encryption and blockchain concepts.

Technologies Used

- Python
- Tkinter
- AES-256 Encryption
- SHA-256 Hashing

Features

1. Encrypt messages and add blocks.
2. Display blockchain details.
3. Decrypt the latest message.
4. Verify blockchain integrity.

How to Run

Install the required library:

"python -m pip install cryptography"

Run the program:

"python aes_blockchain.py"

Conclusion

This project demonstrates message encryption, decryption, and blockchain hash verification.
